# Формирование пешеходных зон — мультифункционального пространства городской среды на примере города Новосибирска
Данный репозиторий содержит набор пространственных данных, использованных при исследовании потенциала формирования пешеходных зон в городской среде на примере города Новосибирска. В него входят как исходные, так и предварительно обработанные слои, применяемые для проведения пространственного анализа и расчёта ключевых показателей.

К исходным данным относятся слои с точками притяжения (amenity.gpkg), пешеходными барьерами (barriers.gpkg), зданиями (building.gpkg), улично-дорожной сетью (highway.gpkg) и остановками общественного транспорта (stops.gpkg). Эти данные представлены в первоначальном виде, до проведения какой-либо фильтрации или отбора.

Также в репозитории представлены обработанные версии тех же слоёв — файлы с индексом _2 в названии. Они содержат данные, прошедшие предварительную фильтрацию и подготовку для дальнейшего анализа. В рамках обработки выполнялся отбор релевантных объектов, необходимых для оценки пешеходного потенциала территорий, а также приведение данных к единой структуре, удобной для расчётов. Файл streets.qgz представляет собой проект QGIS, в котором объединены все используемые слои, настроена их визуализация и частично реализованы результаты анализа.
Дополнительно в репозитории размещён файл выпускной квалификационной работы, в рамках которой применялись представленные данные и разрабатывалась методика оценки пешеходного потенциала.

Представленные материалы могут быть использованы для анализа городской среды и формирования оценки потенциала территорий к пешеходизации.
